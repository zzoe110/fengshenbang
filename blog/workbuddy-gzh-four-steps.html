公众号发一篇文章要开四个后台？我把这活交给AI了：WorkBuddy四步实操

✍️ 外行澯烽哥 📅 2026-10-31 ⏱ 9 分钟
#WorkBuddy教程#公众号排版#AI落地#县域互联网#公众号草稿箱#gzh-design

今天下午，我把一篇文章同时发到了四个地方：官网、公众号、搜狐号、百家号。

全程我没亲手打开过任何一个后台。标题是AI填的，正文是AI粘的，封面是AI传的，连搜狐号那个必选的「创作声明」，都是AI替我勾的。我只干了一件事：在对话框里说话。

傍晚，重庆巫溪网的创始人「鸡血哥」给我打了个电话。不是为了这篇文章，是因为在AI这件事上，我们俩都在学、都在试，正好聊起来，就通了电话交流这事。他是做县域互联网的老兵，一个县城的流量他啃了很多年。

聊到最后我们落在同一个判断上：县域互联网很多伙伴，不是不想拥抱AI，是没人把路蹚出来给他看。

这篇就把路摊开写，一步不藏。

一、先搞清楚 WorkBuddy 是什么

一句话区分：聊天机器人给你答案，WorkBuddy 给你结果。

它跑在你自己的电脑上，能读写硬盘文件、执行命令、操作浏览器。你说「把这篇文章发到搜狐号」，它是真的去打开浏览器、用你已登录的后台、一步步填进去再点发布——不是给你写一段「你可以这样操作」的教程。

我给它配了一批免费的大模型通道（NVIDIA、AMD、商汤、魔搭都提供免费推理 API），日常文字活基本零成本。

二、排版：一个开源技能省掉半小时

公众号排版是所有做内容的人心里的刺——编辑器对格式极为苛刻，套模板还要反复微调，一篇排半小时是常态。

今天两篇文章的排版，用的都是同一个开源技能：gzh-design，公众号大V「甲木」和「摸鱼小李」联名共建，GitHub 上 4200 多 star，完全免费。

三个设计是真懂行：

第一，6套成熟主题拿来即用。摸鱼绿、红白色系、石墨极简、留白禅意、摸鱼票据、橄榄手记，覆盖教程、观点、复盘等主流题材。封面卡、目录、章节编号、关键词下划线全是自动生成。

第二，不满意就一句话改。给个配色或者扔张参考图，它现场生成一整套主题组件库并保存，以后你的号永远这个风格。对想建立统一视觉的县域平台，等于一次配置、永久复用。

第三，双关卡校验脚本。这是「粘贴不掉样式」的技术核心——样式全部内联、每个文字节点强制包裹，再用校验脚本逐条查，不合规打回重做。今天那篇过了 261 处检查、0 错误，才敢直接推草稿箱。

而且不挑模型——排版逻辑在组件库里，DeepSeek、Kimi、通义这些国产模型跑出来效果一致，预算有限的团队用免费模型完全接得住。

三、推送：没有现成技能，就现场造一个

这是今天最值得说的一段：没有哪个现成技能干这件事，是 WorkBuddy 现场给我造了一个。

我对它说：把这堆 HTML 推进我的公众号草稿箱，封面也一起传。它翻出微信官方草稿接口文档，写了一个脚本——取凭证、传正文图片、传封面、建草稿、回读验证，一条链跑通，零第三方依赖。

从那以后流程就固定了：写稿 → 排版 → 进草稿箱。排版技能排完版，脚本自动接手，两分钟后刷新后台，文章安静地躺在草稿箱里，我核对一眼，点群发。

后来我把它整理成了一个正式技能包，叫「公众号AI排版直推草稿箱」。为了方便大家，已经上传到 WorkBuddy 技能库，审核通过后直接在技能库里搜这个名字就能下载使用。

四、这道坎人人都会撞：IP 白名单

第一次跑脚本，微信直接打回：40164, invalid ip。

微信要求：调用接口的机器 IP 必须事先加白。而这道门现在不在公众号后台了——搬到了微信开发者平台。

管理员微信扫码登录 developers.weixin.qq.com → 我的业务 → 公众号 → 基础信息。AppID 在页面顶部，「开发密钥」里点启用拿 AppSecret（只显示一次），IP 白名单也在同一块，点编辑把 IP 加进去，保存后等一分钟生效。

麻烦的是，家用宽带、办公网、手机热点全是动态 IP，我写这篇文章的当晚就变了一次。三个对策：

  1. 报错就加一次（报错里会回显当前 IP，复制即可，最省事）
  2. 用固定 IP 的云主机跑
  3. 判断是不是动态 IP——报错里的 IP 每次不一样就是

这个坑不大，但第一次遇到的人十个有九个会以为接口坏了。更坑的是找路：网上大部分教程还写着「设置与开发 → 基本配置」，那个入口已经迁走了，照着找只会原地转圈。

五、四步上手：装、排、通、推

别看工具一堆，真正要你动手的只有四步。前两步是一次性的，后两步每篇复用。

第一步 · 装（只做一次）

装好 WorkBuddy，新建一个任务，在对话框里打一句：

帮我安装 gzh-design-skill

它自己装，不用找文件、不用配环境。装完不知道怎么用，就问它「这个排版技能怎么调用」，它会直接把现成的提示词给你。

第二步 · 排（每篇都用）

把写好的稿子丢进去。两种姿势随你顺手：直接粘正文，或者拖个 docx 进去，前面加一句「用公众号排版技能把这篇排一下」。

不满意别自己动手调——一句话就行：「把绿色改成蓝色」「标题再大一号」「目录不要了」。它排完给你两样东西：一份 HTML、一张封面图。这两样就是下一步的全部输入。

第三步 · 通（只做一次，也最容易卡）

打开微信开发者平台，管理员微信扫码登录，进「我的业务 → 公众号 → 基础信息」，一次拿三样：

  • AppID：页面顶部，直接抄
  • AppSecret：「开发密钥」里点启用，只显示一次，立刻复制存好
  • IP 白名单：同一块区域点编辑，把当前出口 IP 填进去

存成一个两行的本地文本文件。这一步别急着推，先说一句「先帮我检查能不能连通」——先自检，通了再往下。

第四步 · 推（每篇都用）

一句话：

把刚才那篇推到草稿箱，标题×××，作者×××，摘要×××，开启留言，原文链接填这个网址

两分钟后去后台草稿箱看，图和排版都过一遍眼。没问题——你点群发。

四个字记住：装、排、通、推。装和通一辈子只做一次，之后每篇文章就是「排」和「推」两句大白话。

六、县域互联网能落地什么

巫溪网这类县域平台，痛点就三个字：人太少。小编一个人管公众号、视频号、政府通稿、商家软文。最耗人的从来不是「写」，是「发」——同样的内容，五个后台、五种排版、五种封面。

三件事可以直接落地：

第一，分发自动化。写稿留人脑，排版交排版技能，推送交草稿直推，多平台分发交浏览器技能。四段全链路，没有一段依赖付费服务。

第二，本地商家的内容流水线。一个源稿出 N 个版本：官网版带二维码、公众号版带电话、搜狐百度版是 SEO 长标题。县域平台攥着本地最全的商家资料，这条流水线就是新营收。

第三，GEO——让县城的生意在 AI 回答里被搜到。现在小县城的人找店也开始问 AI 了：「巫溪哪家火锅好吃？」AI 的回答里没有你服务的商家，这就是新的流量缺口，而且几乎没人抢。

七、写在最后

我的建议就一条：别从「学 AI」开始，从「你最烦的那件重复事」开始。每天手动发五个平台？就从分发开始。每周排十篇公众号？就从排版开始。跑通一件，你就懂它了。

一句实话：工具替代的是手，不是脑子。它不帮你写文章，也不替你判断内容好不好。
